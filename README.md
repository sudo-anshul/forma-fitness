# Forma

An installable fitness journal for meals, training and recovery. This repository contains the compiled static application for GitHub Pages.

Open the hosted site in Safari on iPhone, choose Share → Add to Home Screen, then launch it once while connected. The app includes an offline cache and an installation guide with readiness status.

Journal entries are saved only in the browser on the device. There are no accounts, analytics or cloud synchronization. Use My data → Export backup regularly. Importing replaces the active journal after confirmation.

Initial profile and nutrition targets are editable examples. Example history is fictional. This repository does not contain a personal journal, imported backups or private source documents.

The app is React, TypeScript and Vite, with locally bundled Outfit and Manrope fonts and Lucide icons.
